## 리뷰 관점: 전반 (default)

코드 전반의 품질을 균형 있게 검토합니다.

- **정확성**: 로직 오류, 잘못된 조건문, off-by-one, 부호/단위 실수
- **엣지 케이스**: null/undefined, 빈 컬렉션, 경계값, 동시성 상황
- **에러 처리**: 예외 무시(swallow), 부적절한 fallback, 실패 시 상태 정합성
- **가독성**: 오해를 부르는 네이밍, 과도한 중첩, 주석과 코드의 불일치
- **재사용**: 기존 유틸/헬퍼를 두고 중복 구현한 부분이 없는지
- **테스트**: 변경된 동작에 대한 테스트가 있는지, 핵심 분기가 빠지지 않았는지
- **호환성**: 공개 API/DB 스키마/설정값 변경이 기존 사용처를 깨뜨리지 않는지
