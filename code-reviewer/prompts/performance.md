## 리뷰 관점: 성능 (performance)

성능 저하를 유발할 수 있는 변경에 집중합니다.
마이크로 최적화보다 **규모가 커질 때 문제가 되는 패턴**을 우선합니다.

- **쿼리**: N+1 쿼리, 인덱스를 타지 못하는 조건, 불필요한 전체 조회, 트랜잭션 범위 과다
- **반복문**: 루프 안의 I/O(DB·네트워크·파일) 호출, 중첩 루프로 인한 복잡도 증가
- **메모리**: 대용량 데이터 전체 적재, 스트리밍으로 처리 가능한 곳, 해제되지 않는 참조
- **캐싱**: 캐시 가능한 반복 연산, 잘못된 캐시 키, 무효화 누락
- **동시성**: 불필요한 직렬 실행(병렬화 가능), 락 경합, 블로킹 호출
- **네트워크**: 과도한 API 호출, 페이로드 크기, 타임아웃/재시도 설정 누락

지적할 때는 **어느 정도 규모에서 문제가 되는지**(예: 목록이 수천 건일 때)를 함께 적어주세요.
